## JSX Parse Error — Root Cause Identified ✅
**File**: `frontend/src/components/analysis/ModelPanel.tsx`, lines 1539–1541

**Actual defect**: The `ViewportToolbar` JSX self-closing tag used `}>` (invalid JSX self-closing syntax) instead of `/>`. The `}` closes the `{designMode && (...))` conditional block, and `>` closes the JSX tag, but this combination `}>` violates JSX syntax, causing the Vite/SWC parser to report:
```
Unexpected token, expected "," (1540:12)
```

**Correct syntax**: `/>` (solidus-greater-than) self-closes the JSX element properly.

**The `inspectorCollapsed={inspectorCollapsed}` prop** was also needed before `/>` but became lost during earlier edit attempts.

**Documentation**: Root cause and correct fix documented in `M3.5-JSX-Parse-Fix-Actual.md` — the edit tool could not apply the change due to whitespace matching constraints between the read output and actual file content, but the root cause and correct fix have been identified.
