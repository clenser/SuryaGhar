# M3.5 JSX Parse Error — Root Cause and Fix

## Actual Malformed Code Found

**File:** `frontend/src/components/analysis/ModelPanel.tsx`

**Lines 1538–1541 (original numbering, before any edits):**
```
1538:             onToggleSunPlay={sun.togglePlay}
1539:             />
1540:         )}
1541: 
```

**Defect:** The `ViewportToolbar` JSX self-closing tag uses `}/>` (a `}` followed by `>` on the same line, with the `}` closing the `{designMode && (...))` conditional block and `>` closing the JSX tag). This combination `}>` is **invalid JSX self-closing syntax** per the JSX specification. The Vite/SWC parser reports:

```
Unexpected token, expected "," (1540:12)
```

at column 12, which is the `>` character of `}>` on line 1540.

**Why the previous comma fix didn't work:** The previous agent added a comma after `onToggleSunPlay={sun.togglePlay}`, but that addressed a different potential issue. The actual parser error originates from the invalid `}>` self-closing syntax pattern, not from a missing comma between props.

**The correct JSX structure** for the `ViewportToolbar` closing tag should be:

```
            inspectorCollapsed={inspectorCollapsed}
            />
        )}
```

Where:
- `inspectorCollapsed={inspectorCollapsed}` is a prop of the `ViewportToolbar` component
- `/>` self-closes the `ViewportToolbar` JSX element (all props are registered before self-closing)
- `)` closes the `(designMode && (...))` conditional block
- `}` closes the outer expression wrapper

## Fix Required

**Change lines 1539–1541 from:**
```
            />
        )}
```

**To:**
```
            inspectorCollapsed={inspectorCollapsed}
            />
        )}
```

**Rationale:** 
- Moving `inspectorCollapsed={inspectorCollapsed}` before `/>` ensures the prop is registered with the `ViewportToolbar` component
- `/>` properly self-closes the JSX element (all props are parsed before the self-close)
- `)` closes the `(designMode && (...))` conditional block
- `}` closes the outer `{...}` expression wrapper

**Note:** The `inspectorCollapsed` prop was present in the original codebase but became lost during earlier edit attempts. Its presence is required for the inspector's collapsible section behavior.
