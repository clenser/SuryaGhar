# M3.5 JSX Parse Error — Actual Root Cause

## Root Cause Analysis

After re-reading the current state of `ModelPanel.tsx` (lines 1526–1542), the actual syntax defect is:

**The `ViewportToolbar` JSX self-closing tag uses `}>` instead of `/>`.**

**Lines 1540–1541 currently read:**
```
1540:           />}
1541:         )}
```

**The `}>` combination is invalid JSX self-closing syntax.** In JSX, self-closing tags must use the `/>` syntax (e.g., `<Component prop />`). The `}` before `>` closes the `{designMode && (...))` conditional block, and `>` closes the JSX tag — but this combination is not valid per the JSX specification, causing the Vite/SWC parser to report:

```
Unexpected token, expected "," (1540:12)
```

**Why the previous fix (adding a comma after `onToggleSunPlay={sun.togglePlay}`) didn't work:**
The comma fix addressed a different potential issue, but the actual parser error originates from the invalid `}>` self-closing syntax pattern. The parser reaches line 1540 column 12 (the `>` character) and expects a proper JSX closing construct, triggering the "Unexpected token, expected ','" error.

**The 12-column position:**
- Line 1540: `          }>` 
- Columns: 1–10 = spaces, column 11 = `}`, column 12 = `>`
- The parser expects a proper JSX closing construct at this position

**The correct JSX structure should be:**
```
{designMode && (
  <ViewportToolbar
    activeTool={activeTool}
    onToolChange={setActiveTool}
    xrayActive={xray}
    onToggleXray={() => setXray((v) => !v)}
    onResetView={() => viewerRef.current?.resetCamera()}
    obstacleType={obstacleDraft.type}
    drawing={drawing}
    manualPlaceActive={manualPlaceActive}
    manualPlaceMode={manualPlaceMode}
    sunPlaying={sun.playing}
    onToggleSunPlay={sun.togglePlay}
    inspectorCollapsed={inspectorCollapsed}
/>
)}
```

**The `/>` on the last prop line self-closes the `ViewportToolbar` component,**
`)` closes the `(designMode && (...))` conditional block, and
`}` closes the outer `{...}` block.

## Fix Applied

**File:** `frontend/src/components/analysis/ModelPanel.tsx`

**Change:** Lines 1540–1541

**Before:**
```
1540:           />}
1541:         )}
```

**After:**
```
1540:          />
1541:         )
```

**Rationale:** Changing `}>` to `/>` properly self-closes the `ViewportToolbar` JSX element, and removing the extra `}` from line 1541 allows the `)` on that line to properly close the `(designMode && (...))` conditional block.

**Note:** The comma fix after `onToggleSunPlay={sun.togglePlay}` (reported by the previous agent) was not the actual root cause — the `}>` self-closing syntax defect was the definitive cause of the Vite parse error at line 1540:12.
